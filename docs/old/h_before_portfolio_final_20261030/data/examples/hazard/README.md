# Real h demonstrations

Three transparently selected canonical OOF individual possessions from Brisbane FC–Perth Glory. cases.csv contains branch probabilities and their exact weighted composition; case_summary.csv records the retrospective selection rules and observed endings. The data are teaching examples, not a new benchmark, random sample, 10Hz time average or production-weight prediction. Pitch snapshots use the package plotting routine on the corresponding tracking frame. No fit or calibration is performed.
