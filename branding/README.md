# PRESS logo

The approved primary logo shows three defenders closing on a carrier, whose red tracking vector points through the open side.

- `press-logo.svg`: primary vector asset.
- `press-logo.png`: transparent raster export.
- `favicon.png`: square browser icon.
- `build_logo.py`: reproducible vector drawing.
- `proposals/`: earlier logo studies; B matches the approved primary design.

The website header, favicon and repository README use this primary logo.
